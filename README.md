# 🛡️ Fortinet Handbook

> A practical, hands-on Fortinet learning repository covering theory, enterprise labs, troubleshooting, interview preparation, and cheat sheets.

---

## 📖 About

This repository documents my journey of learning and mastering Fortinet technologies through structured documentation and practical EVE-NG labs.

The goal is to create an enterprise-level Fortinet handbook that helps students, network engineers, and cybersecurity professionals understand Fortinet from beginner to advanced level.
